# Concrete Association Portal

A Persian RTL web application for a concrete association.

## Goal

This system manages:
- Member registration and mobile verification
- Company and factory profiles
- Factory equipment and machinery
- Raw material prices
- Concrete mix designs
- Production costs
- Suggested concrete prices
- Aggregated association reports

## Planned Stack

- Backend: ASP.NET Core Web API
- Frontend: React + TypeScript
- Database: PostgreSQL for production
- ORM: Entity Framework Core
- Authentication: secure auth with mobile verification and role-based access
- UI: Persian RTL responsive interface
